# Sandy's Favorite Movies

## Project Summary

Sandy's Favorite Movies is a responsive web application created using HTML, CSS, JavaScript, and jQuery Mobile. The purpose of the website is to allow users to browse favorite movies by genre, learn about the website, and submit their own favorite movies through an interactive form. User submissions are stored using the browser's Local Storage.

---

## Website Structure

```
Home
├── Action Movies
├── Comedy Movies
├── About This Website
└── Favorite Movie Form
```

---

## Page Descriptions

### Home Page
**Purpose:** Introduces the website and provides navigation.

**Buttons and Results:**
- **Action Movies** → Opens the Action Movies page.
- **Comedy Movies** → Opens the Comedy Movies page.
- **About This Website** → Opens the About page.
- **Favorite Movie Form** → Opens the movie submission form.

---

### Action Movies
**Purpose:** Displays favorite action movies.

**Buttons and Results:**
- **Back** → Returns to the previous page.
- **Home** → Returns to the Home page.

---

### Comedy Movies
**Purpose:** Displays favorite comedy movies.

**Buttons and Results:**
- **Back** → Returns to the previous page.
- **Home** → Returns to the Home page.

---

### About This Website
**Purpose:** Explains the purpose of the website and introduces the creator.

**Buttons and Results:**
- **Back** → Returns to the previous page.

---

### Favorite Movie Form
**Purpose:** Allows users to submit their favorite movies.

**Buttons and Results:**
- **Open Movie Menu** → Opens the navigation panel.
- **Home** → Opens the Home page.
- **Action Movies** → Opens the Action Movies page.
- **Comedy Movies** → Opens the Comedy Movies page.
- **About** → Opens the About page.
- **Save Favorite Movie** → Saves the movie information to Local Storage.
- **Clear All Favorites** → Removes all saved movie information.
